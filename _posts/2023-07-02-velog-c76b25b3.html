추천 폰트

D2 Coding

특징

  • 고정폭 서체 모든 글자 폭이 동일하여 코드를 가지런하게 볼 수 있다.
  • 한글 가독성 한글 폰트이기 때문에 한글 가독성이 뛰어나다.

다운로드

  • https://github.com/naver/d2codingfont

Fira

특징

  • 엄청난 특수 기호 표현

'크거나 같다' 같은 수학기호를 >=와 같이 두 기호를 합쳐 작성하지만, 화면 상에서 하나의 기호로 표현해주어 가독성과 직관성이 매우 좋아진다.

아래 코드 예시처럼, 화살표 기호 뿐만 아니라 여러 부등호 또한 직관적인 기호로 변환하여 화면에서 볼 수 있다.

다운로드

  • https://github.com/tonsky/FiraCode

VSCode 폰트 적용

  • Setting.json

    // 하나만 적용
{
	"editor.fontFamily": "'D2Coding'",
	"editor.fontLigatures": true,
}
// 여러 개 적용 (순서대로 적용되며 없는 거는 뒤에서 적용)
{
    "editor.fontFamily": "'Fira Code', Monaco, 'Courier New', monospace",
    "editor.fontLigatures": true
}
